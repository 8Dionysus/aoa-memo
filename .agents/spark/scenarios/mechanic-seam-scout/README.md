# Spark Scenario: mechanic-seam-scout

Use `mechanic-seam-scout` to map one memo mechanic seam before deeper
mechanic work.

## Scope

Read one mechanic package, legacy bridge, owner map, part-local artifact route,
or validation seam. This is a scout scenario; editing is out of scope unless
the user explicitly asks for a small repair.

## Done Signal

The likely active home, legacy route, stronger owner, part-local artifact home,
and next validator are named.

## Stop-line

Do not move mechanic artifacts or author mechanic law during scout-only work.

## Handoff Route

Write a handoff when the seam needs package redesign, part renaming, owner-map
change, generated inventory change, or cross-repo owner judgment.

## Validation

Use `python scripts/mechanics/validate_memo_mechanics.py`,
`python scripts/mechanics/validate_memo_mechanic_parts.py`, or the named package-local
validator only when a repair is performed.
