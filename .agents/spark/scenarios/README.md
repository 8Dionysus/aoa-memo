# Spark Scenarios

Each scenario is a bounded launch route for a standalone Spark session.

Choose exactly one scenario from `.agents/spark/registry.json`, read that
scenario `README.md` and `PROMPT.md`, then finish as `done-or-handoff`.

The scenario directory must provide:

- `README.md`
- `PROMPT.md`
- `templates/result.md`
- `templates/handoff.md`
- `examples/result.example.md`
