- Decision ID: AOA-MEM-D-0082

## Context

`aoa-memo` now has bounded contracts for explicit pull, shadow, canary,
outcome-qualified proposals, mechanical lifecycle, distributed erasure, and
agent-local nomination. The larger set is a research envelope, not evidence
that every contour should become live memory behavior.

## Decision

The admitted R1 memory core is explicit pull over public-reviewed D0 objects
and current public owner refs.

`aoa-memo` owns reviewed meaning, provenance, lifecycle, influence-policy
semantics, semantic proposals, and distributed-erasure composition. It does
not own raw sessions, routes, roles, effects, runtime stores, host facts,
proof verdicts, or training.

Shadow/canary and agent-local promotion contracts may remain as disabled
source surfaces. They perform no live trigger, private ingestion, semantic
auto-write, shared-ledger write, policy promotion, or external effect.
Training remains consumer-zero under `AOA-CENTER-D-0037`.

## Alternatives

- Activate selective canary by default. Deferred because natural OS and
  operator evidence is incomplete.
- Admit private reviewed storage with the public pull path. Rejected because
  physical placement and live erase closure are not admitted.
- Remove the disabled research contracts. Rejected because their fail-closed
  boundaries and falsifiers are useful future constraints.
- Let local outcomes promote shared memory. Rejected by `AOA-MEM-D-0081`.

## Consequences

- `codex_owner_orientation_v0` is the first bounded consumer profile.
- Current-source/lexical recall, citation, currentness, contradiction,
  omission, and no-memory rollback remain mandatory.
- Semantic transitions remain operator-reviewed or absent.
- Mechanical lifecycle stays restricted by `AOA-MEM-D-0079`.
- Erasure stays walkable under `AOA-MEM-D-0080`.
- Disabled C/D surfaces must be excluded if final audit finds a hidden live
  route or authority widening.
