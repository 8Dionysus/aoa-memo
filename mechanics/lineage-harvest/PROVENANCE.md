## Why this package exists

`PATTERN_LINEAGE_MEMORY.md` was left flat after recurrence-support landed
because it was not route-return support. It names a separate operation:
cross-repo recurring signals become pattern-lineage memory candidates only
through evidence, owner route, bounded verdict, retention, and authority gates.

That operation is also not the same as:

- governance authority-boundary memory
- writeback return lanes
- retention outcome memory
- adoption memory
- consumer handoff
- runtime watchtower execution

The package keeps the memo-owned candidate memory visible while stronger owners
keep stronger truth.
