# Lineage Harvest Direction

## Current contour

Lineage harvest gives OS Abyss a memo-owned way to remember repeated
cross-repo patterns without granting the pattern a stronger status.

The mechanic holds one narrow question:

```text
Can this recurring owner-local evidence become a reviewable pattern-lineage
memory candidate, with gates and downstream dossier boundaries still visible?
```

If the question becomes "is it proved", "is it adopted", "is it promoted to
KAG", "is it Tree-of-Sophia canon", "who may act on it", or "what happened at
runtime", this package must route away.

## Operating rule

Lineage-harvest memory must name:

- evidence refs
- source owner route
- bounded verdict refs when promotion is discussed
- retention posture when durable adoption is discussed
- authority check
- downstream owner route
- current candidate status

## Stop-line

Do not treat recurrence as authority. Repetition can justify a candidate,
never proof by itself.
