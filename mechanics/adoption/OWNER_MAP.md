# Adoption Owner Map

| Concern | Owner |
|---|---|
| Adoption memory posture and source refs | `aoa-memo` |
| Router behavior and dispatch implementation | `aoa-sdk` |
| Adoption proof and regression evidence | `aoa-evals` |
| Role rights and actor write authority | `aoa-agents` |
| Recurring adoption choreography | `aoa-playbooks` |
| Runtime storage, workers, and retention execution | `abyss-stack` |
| Authored source meaning | source owner repository |

`aoa-memo` may preserve the adoption candidate and its recall route. It must
not claim that stronger owner behavior has landed.
