# Adoption Direction

The adoption mechanic keeps adoption memory explicit, reviewable, and
candidate-first.

Current direction:

- preserve source refs before any adoption claim
- keep forgetting and revision visible as memory posture, not final policy
- route adoption proof to `aoa-evals`
- route dispatch behavior to `aoa-sdk`
- route live storage and retention execution to `abyss-stack`

Do not widen adoption language into automatic promotion or hidden memory
authority.
