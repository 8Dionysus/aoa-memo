# Consumer Handoff Direction

## Current

Keep memo useful to neighboring repositories by publishing bounded handoff
surfaces with explicit owner splits, source refs, recall modes, scopes, bridge
faces, and guardrail cases.

## Operating Contour

- expose only memo-owned descriptors and public-safe memory surfaces
- keep consumer field lists separate from grants, rights, verdicts, and runtime
  action
- make scope expansion explicit for playbooks and orchestrators
- keep KAG and ToS bridge exports source-linked and weaker than graph or source
  truth
- hand memory-quality risks to `aoa-evals` as cases, not scores or verdicts
- update generated refs and validators when active handoff paths move

## Stop-Line

If a change needs actor policy, scenario choreography, eval scoring, graph
normalization, ToS source interpretation, routing behavior, or runtime storage,
route away before expanding this mechanic.
