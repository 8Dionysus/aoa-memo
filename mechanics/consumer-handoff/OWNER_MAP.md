# Consumer Handoff Owner Map

| Concern | Owner |
|---|---|
| Memo handoff descriptors, recall modes, scope grammar, bridge/export notes, and guardrail case descriptions | `aoa-memo` |
| Actor identity, read/write/promotion/freeze rights, approvals, and handoff policy | `aoa-agents` |
| Scenario composition, campaign choreography, and return posture | `aoa-playbooks` |
| Scoring, pass/fail logic, evidence weighting, and proof verdicts | `aoa-evals` |
| Graph substrate normalization, federation activation, and derived KAG semantics | `aoa-kag` |
| Authored ToS meaning, fragments, concepts, nodes, and lineages | `Tree-of-Sophia` |
| Dispatch behavior and route compression | `aoa-routing` |
| Runtime stores, workers, receipts, and operational execution | `abyss-stack` or runtime owner |

`aoa-memo` may publish a safe consumer handoff surface. It must not claim that
the consumer accepted, proved, activated, routed, or executed the next step.
