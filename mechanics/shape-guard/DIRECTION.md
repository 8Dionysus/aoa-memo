# Shape Guard Direction

## Current

Keep memo growth operation-first, source-linked, and reviewable by pruning
memory-object, trust-field, recall-family, mechanic-package, and action-trigger
inflation before it hardens into public shape.

## Operating Contour

- prefer existing reviewed recall objects before adding new object families
- keep mechanic packages named by repeatable memory operations, not topics
- reject scalar trust fields that collapse authority, confidence, freshness,
  salience, and recall posture into one number
- route proof, action authority, KAG promotion, and runtime execution to
  stronger owners before memory wording pretends to own them
- keep old via-negativa governance placement as provenance, not active route

## Stop-Line

If shape review requires deleting owner truth, changing runtime state, replacing
proof logic, or granting role/action authority, route away before expanding
this mechanic.
