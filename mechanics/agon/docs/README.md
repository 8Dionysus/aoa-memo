# Agon Memo Mechanic Docs

This directory contains source docs for the Agon memo mechanic.

The files here preserve candidate memory, source-ref, evidence-package,
retention, bridge, and stage landing posture for Agon-related work. They do not
create live arena sessions, verdict law, durable scars, rank mutation, KAG
promotion, stats authority, or Tree-of-Sophia canon.

## Stop-Lines

Agon memo surfaces may say:

- what candidate memory can be preserved
- which evidence package or bridge shape is reviewable
- what source refs and owner routes are required
- what remains deferred, rejected, quarantined, or not-yet-authoritative

They may not say:

- that a verdict has been proven
- that a scar, rank, or retention result has been durably written
- that a KAG promotion or Tree-of-Sophia canon claim has landed
- that runtime scheduling or storage is active
- that `aoa-memo` owns Agon source doctrine
