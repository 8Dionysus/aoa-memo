# Agon Memo Mechanic

Agon is the memo-side mechanic for preserving candidate memory, source refs,
evidence packages, bridge posture, retention/rank memory boundaries, and wave
landing receipts around Agon without becoming the source Agon mechanic.

## Mechanic card

- Status: `landed`

### Trigger

Use when Agon-related candidate memory, scar or rank memory posture,
retention intake, evidence packages, KAG/Sophian bridge refs, SLC/VDS bridge
memory, mechanical trial memo intake, or wave landing notes must become
explicit and reviewable.

### Memo owns

Memo owns the public, source-linked memory shape: candidate intake posture,
prebinding memory, evidence-package refs, bridge memory, stop-lines, recall
routes, and landing receipts.

### Stronger owner split

- `Agents-of-Abyss` owns the source Agon mechanic, trial posture, verdict
  meaning, scar/rank doctrine, and stronger center law.
- `aoa-evals` owns proof and verdict-quality evidence.
- `aoa-kag` owns downstream graph substrate normalization and promotion.
- `Tree-of-Sophia` owns authored Sophian canon.
- `aoa-agents` owns actor rights, handoff authority, and write authority.
- `aoa-stats` owns derived movement summaries.
- `abyss-stack` owns runtime storage, workers, and private/live retention.

### Inputs

Reviewed source refs, candidate memory notes, evidence package definitions,
bridge candidates, wave landing receipts, recurrence review candidates, and
owner-handoff notes.

### Outputs

Bounded Agon memo docs, source-ref maps, generated companion inputs, manifest
refs, quest obligations, test-backed examples, and owner handoff routes.

### Must not claim

- an Agon trial ran
- a verdict was proven
- a scar, rank, or retention result was durably written
- a KAG promotion or Sophian canon claim landed
- runtime scheduling or private storage exists
- `aoa-memo` owns source Agon doctrine

### Validation

Use the validation lane in [AGENTS](AGENTS.md#validation).

### Next route

Route source Agon doctrine to `Agents-of-Abyss`, proof to `aoa-evals`, graph
lift to `aoa-kag`, authored canon to `Tree-of-Sophia`, role authority to
`aoa-agents`, derived stats to `aoa-stats`, and runtime retention to
`abyss-stack`.
