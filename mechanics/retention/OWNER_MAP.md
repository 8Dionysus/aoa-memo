# Retention Owner Map

| Concern | Owner |
|---|---|
| Retention review posture, markers, and source refs | `aoa-memo` |
| Mechanical lifecycle plan and semantic proposal meaning | `aoa-memo` |
| C14-C17 erasure scope, manifest closure, ER0 canonical/read-model work, and ER9 content-minimized tombstone | `aoa-memo` |
| Raw `.aoa` evidence and local session-memory ports | `aoa-session-memory`, only after an explicit operator privacy decision |
| Runtime stores, caches, nervous indexes, exports, backup/restore descendants, workers, and schedules | `abyss-stack` |
| Embedding, graph, and KAG projection invalidation, erasure, rebuild, and recovery receipts | `aoa-kag` |
| Host-local path ownership, storage policy, physical evidence, and recovery checks | `abyss-machine` |
| Experiment replay copies and distributed-erasure reference verdict | `aoa-evals` |
| Training datasets, checkpoints, and real model-unlearning execution | source owner for the exact model/training repository |
| Future control-plane admission | `aoa-sdk` |
| Retention proof and regression evidence | `aoa-evals` |
| Actor rights and handoff authority | `aoa-agents` |
| Stronger governance policy | governing owner repository |

`aoa-memo` may preserve retention evidence and recall routes. It must not claim
retention execution, raw-session authority, runtime or host erasure, projection
execution, backup purge, or model-unlearning authority.
