# Agon Quest Lane

This lane holds Agon memo follow-through quest sources.

Use it for public, owner-routed Agon memo obligations that must survive the
current diff but are not generated `AOA-MEM-Q-*.yaml` quest catalog entries.
Route source Agon doctrine to `Agents-of-Abyss` and keep memo claims bounded to
candidate memory, evidence, bridge, retention/rank memory posture, and
follow-through.

Markdown sources in this lane use the contract in
[`QUEST_SOURCE_CONTRACT`](../../mechanics/questbook/docs/QUEST_SOURCE_CONTRACT.md).
